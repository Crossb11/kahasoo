# Project rules
- Shopify remains the source of product prices, variants and checkout; resolve product photography through a shared module so cached carts cannot reintroduce retired images.
- Store uploaded media as Lovable asset pointers; keep gallery photography separate from the sale catalog to avoid inventing products or prices.
- Reuse the same creation gallery on the homepage and gallery page so every supplied photo is visible in both without relying on Shopify product availability.
- Lay out the shared gallery with CSS masonry columns and intrinsic image proportions so mixed portrait and landscape photos pack without empty grid cells.
